Brain Puzzle Hub is an Offline First Android puzzle collection developed in C# and .NET MAUI is a combination of 2048, a 15-Puzzle slider and Minesweeper in a single application. 
It allows local account registration and login, keeps the best scores per game and features a Daily Challenge that randomly selects one of the games. 
The use of the device is not limited to a conventional UI: Native vibration feedback, daily reminder notifications and location access.
